# Presentaciones

1. Una idea por diapositiva. Estructura típica: portada → agenda → 3 a 8 diapositivas de contenido → cierre
   (conclusiones o llamada a la acción).
2. Títulos que dicen la conclusión («Las ventas crecieron 18 %»), no el tema («Ventas»).
3. Viñetas cortas (máximo 5, dos niveles como mucho); usa diapositivas de dos columnas para comparar y de imagen
   cuando el usuario dio imágenes.
4. Pon en las notas del orador lo que hay que decir (2–4 frases por diapositiva).
5. Crea el archivo con `create_presentation`. Responde en dos líneas: cuántas diapositivas y dónde quedó.
