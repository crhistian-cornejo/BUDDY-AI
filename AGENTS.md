# Buddy — for every coding agent

The guide for this repository is [CLAUDE.md](CLAUDE.md): read it first. It is written for any coding agent (Claude Code, Codex, Antigravity) and its rules apply to you too; only the commit trailer named there is Claude Code's own.

One rule to keep in mind even before reading it:

- **No real personal data in the repo.** This repository is public. Tests, examples, doc comments, fixtures, previews, docs and commit messages use invented data only: never the owner's real amounts (rent, salary, spending), people's names, e-mail, addresses, or the links and IDs of their accounts and Notion pages, nor anything read from their mail, files or chats. Real data is for local checks only (the app's data folder or a scratch file outside the repo, never a tracked file). Before a commit, replace every real value with an invented one of the same shape (`S/. 1,200`, «Juan P.», `0123456789abcdef…`) and read the staged diff for what is left. A leak in a public repo cannot be taken back: it is copied within hours.
