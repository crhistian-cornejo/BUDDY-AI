# Mika's sounds

Generated by [`tools/gen-sounds.mjs`](../../tools/gen-sounds.mjs) — edit the recipes there and run
`node tools/gen-sounds.mjs`; do not edit the WAVs or this file by hand.

All 28 sounds are original and synthesised from scratch (no samples, no third-party material).
Sound language: *engineering workshop, friendly and tiny* — vibraphone-like chimes, rounded triangle
blips with a slight glide, relay clicks, soft servo whirrs, pneumatic puffs and muted thunks, with a
touch of FM and bit-crush and a tiny room. Melodic material sits on G major pentatonic so sounds that
overlap in the apps stay consonant.

Format: 48 kHz, 16-bit, stereo PCM WAV (the slot format both apps load). Master: 18 Hz high-pass and
exact zero mean (no DC), raised-cosine fades (6 ms in, 10 ms out, first and last samples are 0), peak
normalised to -3 dBFS for event sounds, -5 dBFS for UI sounds and -8 dBFS for the micro feedback that fires
constantly (the apps play everything at ~12 % volume). The build is deterministic: re-running the
script produces byte-identical files; `--check` verifies that.

Several sounds are loaded by both apps but not played by any code path yet (they are marked below);
they are ready for the emotes and states that reference them.
